## Week 3 – Variables, Data Types & Input/Output

### 🎯 Objectives

- Declare and use variables of different data types (`int`, `double`, `String`, `char`).
- Read user input using the `Scanner` class.
- Perform arithmetic operations and handle edge cases (e.g., division by zero).
- Format output using `System.out.printf()`.

### 📄 Files

| File | Description |
|------|-------------|
| `SimpleCalculator.java` | Reads two numbers and an operator, performs arithmetic with zero-division check, and prints a formatted result. |
| `AverageCalculator.java` | Reads a student's name and 3 test scores, calculates total and average, and prints a formatted report. |
| `ItemCost.java` | Reads an item name, integer quantity, and double unit price, then calculates and displays the total cost. |

### 🛠️ How to Compile and Run

Make sure you have the [Java JDK](https://www.oracle.com/java/technologies/downloads/) installed, then:

```bash
# Navigate to the week03 folder
cd week03

# Compile a file
javac SimpleCalculator.java

# Run the compiled class
java SimpleCalculator
```

Repeat for the other files:

```bash
javac AverageCalculator.java
java AverageCalculator

javac ItemCost.java
java ItemCost
```
